# Knowledge Graph Viewer Skill

启动可视化 server，让用户在浏览器实时看知识图谱，并能直接在页面上把 draft 边
标记为 verified。server 是**按需启动**的查看工具，看完即停，不是常驻服务。

## 何时触发

用户说："看看图谱" / "可视化" / "打开关系图" / "graph view" / "看有哪些系统" /
"看看边对不对" / "看一下系统关系" 等。

## 步骤

### 1. 后台启动 server

用 Bash **后台**运行（`run_in_background: true`，不要前台——前台会阻塞会话）：

```
python -X utf8 .claude/kg/tools/gen_graph_html.py --serve --no-open
```

- 默认从项目根的 `.claude/kg` 读图谱；可用 `--root` / `--kg` 指定其它位置。
- `--no-open`：不自动开浏览器——由你把 URL 给用户点开，更可控、跨环境稳定。
- 端口默认 `0` = 自动选可用端口，避免冲突；需要可加 `--port <n>`。

### 2. 从启动输出读 URL

server 起来后（约 1–2 秒）会在后台任务输出打印：

```
知识图谱可视化 server 已启动
  打开: http://127.0.0.1:<port>
```

读后台任务的输出文件拿到这个 URL（端口是动态的，必须从输出读，不要猜）。

### 3. 把地址给用户

告诉用户在浏览器打开该地址。页面能力：

- **实时数据**：server 跑着时，图谱的任何改动刷新页面即见。
- **点击 draft 边（虚线黄）** → 弹框填原因 → 标记为已验证，边变实线绿。
  这个写操作走 `kg_core.verify_edge`，校验 / changelog / 反向索引全部生效，
  与 AI 调 `kg_verify_edge` MCP 工具完全等价（守治理层）。
- 节点点击看详情（代码路径、踩坑、使用统计、变更历史）、域筛选、运营汇总。

### 4. 看完停止 server

用户看完，或明确说"关掉 / 不用了 / 停一下"，用 **TaskStop** 停掉后台 server 任务，
释放端口。**不要让 server 一直跑着**——它是按需查看工具。

## 注意

- server 仅绑 `127.0.0.1`，不暴露局域网，安全。
- 启动失败（图谱目录不存在、JSON 损坏等）会在输出报错，读输出诊断后告诉用户。
- 这只解决"看"；查/改图谱内容仍走 `kg-consult` skill 的 kg MCP 工具。
